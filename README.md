# CodeAlpha Hangman Game

A simple console-based Hangman game written in Python.

## Features
- Randomly chooses from five preset words.
- Allows up to six incorrect guesses.
- Checks invalid and repeated inputs.
- Displays the word as letters are guessed.

## Requirements
- Python 3.8 or newer

## How to Run
1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

```bash
python hangman.py
```

On some systems, use `python3 hangman.py`.

## Example
```text
Welcome to Hangman!
Guess the word. You can make up to 6 wrong guesses.

Word: _ _ _ _ _ _
Wrong guesses left: 6
Enter one letter: p
Correct!
```
